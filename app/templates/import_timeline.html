How to get the file

Android: Settings → Location → Location services → Timeline → Export Timeline data. Saves a file called Timeline.json, usually to your Downloads folder.

iPhone: Open Google Maps → tap your profile picture → Settings → Location & privacy → Export Timeline data → Save to Files.

Get that file onto whatever device you're using to open this page (email it to yourself, AirDrop, save to a cloud drive — whatever's easiest), then upload it below.
